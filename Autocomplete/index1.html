Brute Force

Mengecek setiap kata dalam array satu per satu menggunakan startsWith(). Semakin banyak data, semakin lambat.

for (let word of words) {
  if (word.startsWith(input))
    results.push(word);
}

Trie (Prefix Tree)

Struktur tree di mana setiap node merepresentasikan satu huruf. Pencarian hanya mengikuti path huruf demi huruf.

node = root;
for (let char of input) {
  node = node.children[char];
}
return node.words;
